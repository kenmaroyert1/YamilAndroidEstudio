📋 PASOS PARA ANDROID STUDIO:

1. En Android Studio, crea un nuevo proyecto:
   File > New > New Project > Empty Activity
   
2. Configura:
   • Name: Proyecto1
   • Package name: com.example.proyecto1
   • Language: Kotlin
   • Minimum SDK: API 24

3. Crea las carpetas necesarias en:
   app/src/main/java/com/example/proyecto1/
   
   Carpetas a crear:
   - model/
   - data/
   - viewmodel/
   - navigation/
   - ui/
     - screens/
     - theme/

4. Copia cada archivo .kt en la carpeta correspondiente

5. Sync Gradle

6. Run!
