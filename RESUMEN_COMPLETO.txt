📋 PASOS DETALLADOS PARA ANDROID STUDIO:

PASO 1: CREAR EL PROYECTO
--------------------------
1. File > New > New Project > Empty Activity
2. Name: Proyecto1
3. Package name: com.example.proyecto1
4. Language: Kotlin
5. Minimum SDK: API 24

PASO 2: CREAR LAS CARPETAS
---------------------------
En Android Studio, navega a: app/src/main/java/com/example/proyecto1/

Haz click derecho en "proyecto1" y crea estos packages:

✅ model
✅ data
✅ viewmodel
✅ navigation
✅ ui

Luego, click derecho en "ui" y crea:

✅ ui.screens
✅ ui.theme

----------------------------

PASO 4: SYNC GRADLE
--------------------
Una vez copiados todos los archivos:

1. En Android Studio, haz click en: File > Sync Project with Gradle Files
2. Espera a que termine el proceso
3. Verifica que no haya errores rojos

PASO 5: RUN
-----------
1. Conecta un dispositivo o inicia un emulador
2. Click en el botón verde "Run" (▶️)
3. La app debería iniciar mostrando la pantalla de bienvenida
