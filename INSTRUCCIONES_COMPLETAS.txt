🚀 CÓMO EJECUTAR EN ANDROID STUDIO
═══════════════════════════════════════════════════════════════════════════

PASO 1: SINCRONIZAR PROYECTO
────────────────────────────────────────────────────────────────────────────
1. En Android Studio, verás banner "Gradle files have changed"
2. Click "Sync Now"
3. Espera a que termine (puede tardar 1-2 minutos)
4. Verifica que no haya errores en la pestaña "Build"

PASO 2: CREAR/INICIAR EMULADOR
────────────────────────────────────────────────────────────────────────────
1. Tools → Device Manager (o icono de celular en la barra)
2. Si NO tienes emulador:
   - Click "Create Device"
   - Selecciona: Pixel 5
   - Next → API 34 (Android 14)
   - Download si es necesario → Next → Finish
3. Click ▶️ al lado del emulador para iniciarlo
4. Espera a que el emulador encienda completamente

PASO 3: EJECUTAR LA APP
────────────────────────────────────────────────────────────────────────────
1. En la barra superior, verifica que dice "composeApp"
2. Click en el botón verde ▶️ "Run"
3. Selecciona el emulador de la lista
4. ¡La app se instalará y abrirá automáticamente!

3.2 PROBLEMA Y SOLUCIÓN:
────────────────────────────────────────────────────────────────────────────
PROBLEMA:
La universidad necesita gestionar la reserva de espacios físicos (aulas,
salas de estudio, laboratorios, cabinas) de forma rápida y controlada para
estudiantes, profesores y personal administrativo. El proceso actual es
manual, genera conflictos de horarios y falta de visibilidad de disponibilidad.

SOLUCIÓN:
App móvil "UniReservas" desarrollada en Kotlin Multiplatform que permite:
• Acceso diferenciado por tipo de usuario
• Reserva rápida desde dispositivos móviles
• Visualización de disponibilidad en tiempo real
• Gestión centralizada de reservas activas
• Historial completo para auditoría
• Sistema de ayuda integrado

ERROR: "Unresolved reference"
SOLUCIÓN: 
1. File → Invalidate Caches → Invalidate and Restart
2. Build → Clean Project
3. Build → Rebuild Project

ERROR: "No devices available"
SOLUCIÓN: Crea emulador (ver PASO 2)

ERROR: App se cierra al abrir
SOLUCIÓN: 
1. Abre Logcat (View → Tool Windows → Logcat)
2. Busca líneas rojas con "Exception"
3. Verifica que todos los .kt estén en la carpeta correcta

ERROR: "Gradle sync failed"
SOLUCIÓN:
1. Tools → SDK Manager → SDK Tools
2. Instala "Google Play Services"
3. File → Sync Project with Gradle Files
