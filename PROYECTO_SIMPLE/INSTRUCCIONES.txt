  CÓMO USARLO EN ANDROID STUDIO
═══════════════════════════════════════════════════════════════════════════

PASO 1: Reemplazar MainActivity.kt
   
   1. En Android Studio, busca:
      composeApp/src/androidMain/kotlin/com/example/proyecto1/MainActivity.kt
   
   2. Abre el archivo MainActivity.kt que está en PROYECTO_SIMPLE
   
   3. Copia TODO el contenido (Ctrl+A, Ctrl+C)
   
   4. Pega en el MainActivity.kt de Android Studio (Ctrl+A, Ctrl+V)
   
   5. Guarda (Ctrl+S)

PASO 2: Reemplazar build.gradle.kts
   
   1. En Android Studio, busca:
      composeApp/build.gradle.kts
   
   2. Abre el archivo build.gradle.kts que está en PROYECTO_SIMPLE
   
   3. Copia TODO el contenido (Ctrl+A, Ctrl+C)
   
   4. Pega en el build.gradle.kts de Android Studio (Ctrl+A, Ctrl+V)
   
   5. Guarda (Ctrl+S)
   
   6. Click en "Sync Now" (banner amarillo)

PASO 3: Eliminar archivos innecesarios (OPCIONAL)

   Estos archivos ya NO se necesitan, puedes eliminarlos:
   - Navigation.kt
   - ReservaViewModel.kt
   - ReservaRepository.kt
   - Todas las pantallas en ui/screens/ (WelcomeScreen, LoginScreen, etc.)
   - Todos los archivos en model/ (Usuario, Sala, Reserva)
   - Theme.kt y Type.kt (el proyecto usa MaterialTheme por defecto)

PASO 4: Ejecutar

   1. Crea/Inicia un emulador (Device Manager → Create Device)
   
   2. Click en el botón ▶️ Run
   
   3. Selecciona el emulador
   
   4. ¡La app debería funcionar!

  SI QUIERES AGREGAR MÁS BOTONES O PANTALLAS
═══════════════════════════════════════════════════════════════════════════

Es muy fácil:

1. Agregar una nueva pantalla:
   - Añade: "nuevaPantalla" -> PantallaNueva { pantallaActual = "otra" }
   - Crea la función: @Composable fun PantallaNueva(onAccion: () -> Unit) { ... }

2. Agregar más botones:
   - Copia cualquier Button { } existente
   - Cambia el texto y la acción onClick

3. Cambiar colores/texto/tamaño:
   - Todo está en el mismo archivo, solo edita los valores
