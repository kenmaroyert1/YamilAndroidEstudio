📝 CÓDIGO DEL MainActivity.kt:

package com.example.proyecto1

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import com.example.proyecto1.navigation.ReservaApp
import com.example.proyecto1.ui.theme.ReservaSalasTheme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            ReservaSalasTheme {
                ReservaApp()
            }
        }
    }
}

═══════════════════════════════════════════════════════════════════════════════

🎯 FLUJO DE LA APLICACIÓN:

1. MainActivity inicia → llama a ReservaSalasTheme → llama a ReservaApp()

2. ReservaApp() (en Navigation.kt) inicia el NavHost con:
   startDestination = Screen.Welcome.route
   
3. Screen.Welcome muestra WelcomeScreen con:
   - Logo de la app
   - 4 nombres del equipo ⭐ PANTALLA 1 DEL PARCIAL
   - Botón "Comenzar"

4. Al presionar "Comenzar" → navega a LoginScreen ⭐ PANTALLA 2 DEL PARCIAL
   - Campo email
   - Campo contraseña
   - Selector tipo de usuario
   - Botón "Iniciar Sesión"

5. Al iniciar sesión → navega a HomeScreen ⭐ PANTALLA 3 DEL PARCIAL
   - Búsqueda de salas
   - Listado de salas
   - Bottom Navigation con 5 opciones

═══════════════════════════════════════════════════════════════════════════════

✅ LO QUE HACE EL MAINACTIVITY:

📱 onCreate(): Se ejecuta cuando la app inicia
   └─ setContent { }: Define el contenido visible
      └─ ReservaSalasTheme { }: Aplica el tema (colores, tipografía)
         └─ ReservaApp(): Inicia el sistema de navegación
